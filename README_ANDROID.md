# A股研究驾驶舱 Android v4.6

本版将原先分散的七个入口整合为五个一级页面：总览、市场、机会、组合、研究。

- 总览：集中展示后台状态、四层决策链、市场指数、潜在主线、板块内个股、2000万元影子组合净值与数据审计。
- 市场：指数行情、行业/概念热力图、资金与广度排序。
- 机会：板块雷达、个股证据池和完整决策链三种视图。
- 组合：后台自动影子组合和本机手工账本严格分开；自动组合再分为概览、持仓、成交、报表。
- 研究：最新版研究准入、历史冻结证据和形态实验室。

策略计算与模拟买卖由云端定时任务完成，APK只同步已落库结果，并使用手机SQLite保存最后一次成功数据。程序不连接券商，不发送真实订单。


v4.6：研究页读取云端 strategyResearch 的真实审核证据与分阶段验证进度。策略页显示候选买入区间、保护线、持有/退出解释，以及同起点的买卖管理/简单持有、做T/无T组合对照。旧后端未提供报告时显示未知，不能默认打勾。

v4.4、v4.5 原有构建补丁已应用到源码，构建时不再重复应用。应用ID沿用 v4.5 selection，版本46。新规则仍为影子研究；编译通过不等于投资收益已经验证。
