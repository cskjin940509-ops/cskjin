# a股筛选池 v4.5 实施说明

版本：v4.5-selection-pool-core-t。仅影子模拟，不连接券商；参数尚未通过样本外验证。

## 本次解决的问题

旧引擎把未进入当轮候选榜的持仓目标直接设为零，造成隔日集中卖出。生产入口现在调用独立持仓状态机，候选缺失仅停止加仓；没有明确退出证据不会清仓。

## 规则与实现

| 环节 | 已实施规则 |
| --- | --- |
| 大盘 | 当日核心指数＋至少2000只覆盖的全市场涨跌广度决定风险、防守、中性、积极、强势状态；仓位上限10%、25%、60%、80%、100%。缺关键广度/时点则停买；指数急跌仍可触发风控。宏观五类证据未齐时上限收紧至30%，不虚构四项情绪指数权重。 |
| 板块 | 潜在/确认状态才允许新增；B0量价广度和B1两融、B2 ETF、B3资金至少两类，含至少一类资金；两融数据日期必须早于决策日。 |
| 股票 | 完整板块成员样本覆盖至少95%，固定量价资金横截面评分排名前20%；历史5/20日成交额比1.2–2.5；当日涨幅≤3.5%，跌幅≥-2.5%；5日相对板块扩张≤5个百分点；双源行情均新鲜且偏差≤0.3%。 |
| 相对买点 | 20日均线附近回撤后，3个间隔3–10分钟的有效快照止跌回升；或突破位回踩确认。历史日线只使用已完成交易日。价格便宜或跌得多本身不是买点。 |
| 建仓 | 潜在主线2.5%、确认主线4%；最多加仓2次，单股采用8%保守上限。草案10%龙头例外保留为参数但未自动启用。未知相关分组按同一组处理，上限35%；板块25%。 |
| 执行 | 普通买卖窗口10:00–10:30、14:30–14:50；3个不同且间隔足够的快照确认；一般权重变化不足3个百分点不交易，首次小仓/已确认部分成交余量例外。双边普通换手≤净值20%。 |
| 观察 | 买入后2个完整交易日；日级失效1日观察、2日减半一次、3日退出；缺失某真实交易日的证据打断连续确认；不把周末/假期/多次任务运行计为多日。 |
| 止损止盈 | 1.5×ATR14/价格，距离限制4%–8%；缺ATR保守4%并标注。盈利8%后启动2×ATR移动保护（4%–8%）。风险线只收紧；止损优先于持有期。 |
| 失效退出 | 连续两日板块衰退且两类证据恶化退出；个股资金快速转负并显著弱于板块减半；板块过热且资金不跟随减1/3。每种减仓事件只生成一次固定数量订单。 |
| 待退出 | T+1、跌停、过期报价或容量不足均保留剩余订单；风险退出优先于常规操作。部分成交只扣实际数量，整仓尾数可一次卖出。 |
| 风控 | 当日单位净值-1.5%停买；-2.5%把首次触发时的总仓位目标降低25%，不每5分钟反复乘0.75；确认日终回撤-5%仓位上限减半；-8%至少暂停5个真实交易日且等待复核。 |
| 会计 | 2000万元容量和100万元历史阶段全部保留；新规则不修改41笔既有成交；保留基金份额法及完整历史净值。正式回撤仅使用经确认的收盘估值，旧版未确认统计另列，不把盘中点当收盘。 |

## 做T：保守的先卖后买模式

只使用满足T+1的底仓，每股每日最多1组，最多昨日底仓20%且不超过组合净值1%。仅当20日趋势较平、5日涨跌未形成明显单边走势、价格偏离VWAP并出现冲高转弱时，才允许模拟卖出。三轮报价必须连续，间隔3–10分钟；定时任务延误时暂停，不用稀疏数据冒充分钟级信号。

预期价差需覆盖双边佣金、税费、点差和保守冲击预算，且净余量至少0.3个百分点。买回还需回到事先保存的目标区间、出现止跌回升、重新通过双源/仓位/容量/板块检查，且按可成交价格计算仍有至少0.3%净余量。风险退出优先，禁止为配对强行追价买回。14:50以后不发起买回；未买回和部分买回保留机会损益。买回的股票计入当天买入冻结数量，不可以当天再次卖出。

低买高卖的先买模式本版不自动启用，以免增加下跌中的敞口。趋势上涨时优先持有底仓；震荡时才考虑小比例做T。

做T配对净收益 = 已配对卖出净额 − 买回含费成本。未配对机会损益 = 剩余股数对应的卖出净额 − 同股数当前持有价值。两者相加是做T股数的局部持有对照，**不是完整策略的无T回测收益**；不重复加到净值，不改写会计平均成本。没有历史分钟数据支持时，不能宣称已找到最低点、固定胜率或稳定降本效果。每20个交易日提示前向滚动复核，不自动根据结果回改历史。

## 数据不足的实际行为

当前源可能缺全市场广度、板块5日收益、完整ADV20、第二路新鲜报价或经确认的昨日收盘净值。缺失时明确显示未通过原因，不默认放行。历史日线一次按日缓存；持仓板块单独记录并持续取成员数据，即使暂时不在新买榜单中也保持风险跟踪。新版本初次启动可能需等待下一次有效收盘，以建立可靠的日亏损基准。

## 验证范围与安装

单元测试覆盖掉榜不清仓、日级确认、T+1、跌停、部分成交余量、报价过期、止损线不放宽、未来数据排除、重复运行不变成三次确认、实际做T配对/费用/每日次数。另用原生产账本副本执行完整入口与契约检查，核对41笔旧成交、现金及持仓均不变。尚未完成历史分钟样本外回测、手机真机运行与长期收益验证。
