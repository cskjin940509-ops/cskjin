# v4.6 策略目标与修改说明

目标：提前发现潜力板块和个股，优化买入及退出，按需研究做T。用扣除费用后的超额收益、回撤及跨行情稳定性评价。相对低位和高位是优化方向，不能把事后最低/最高价当作已知买卖点。

## 本次代码修改

1. 首次出现的早期候选按日、板块冻结，保存当时完整成员、候选（包括未通过买点的候选）、参数与代码指纹、时点以及哈希。后续掉榜仍跟踪原成员；不删除缺失报价来提高成绩，不重写首次排名。
2. 固定10个交易日主观察窗口，5/20日作为辅助。候选与当时板块等权、B0涨幅前20%基线比较。按信号日期汇总；60个日期只是复核门槛，不能自动认证有效。
3. 同一起点初始化三个独立影子账本：现有管理含T、相同核心规则无T、简单入场与固定10个完整交易日持有。后者取消回踩及阻力空间过滤，仍使用同一候选质量筛选、双源报价、仓位容量、成交窗口、硬止损和组合风控。它衡量整组买卖规则的差异，不代表单参数因果贡献。
4. 三组独立现金、持仓、费用、滑点、待成交订单；关闭T的两组不会调用T成交。比较使用相同日期的确认收盘单位净值，包含未买回的卖飞影响。资金事件变化会暂停对比，等待核对。原来的T局部配对指标保留，不能代替完整组合对照。
5. 每个候选增加买入观察区间、保护线、阻力参考、等待条件和失效说明；每个持仓显示持有、观察、待退出或等待新行情及相应理由。
6. 研究页取消固定true/false的五项审核，读取云端实际完成数量、时间、证据位置和缺口。缺少报告时显示未知。available_at缺失不能凭T+1说明通过；当前前向覆盖不冒充2017年至今历史覆盖。
7. 安卓沿用v4.5应用ID，版本升级4.6.0。将已有v4.4/v4.5构建补丁落实到源码，避免重复打补丁后构建。
